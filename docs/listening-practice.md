# Новые тексты и аудио на пройденном греческом

Для работы через Codex используется отдельно установленный скилл `greek-listening-practice` (`~/.codex/skills/greek-listening-practice/SKILL.md`). Он не входит в этот репозиторий. Скрипты и постоянные правила находятся здесь, в `scripts/` и `AGENTS.md`; для генерации через скилл его нужно установить отдельно.

Обычная просьба: «Сделай два новых диалога о семье и работе на нашем словаре» или «Сделай короткий монолог для аудирования». Можно явно вызвать `$greek-listening-practice`.

- Монолог: один персонаж и один голос LFM.
- Диалог: ровно два персонажа и два разных голоса LFM, постоянно закреплённые за ролями.
- Текст новый; темы, грамматика и лексика берутся из текущего профиля, словаря и проверенных референсов. Перечитывание исходного урока — отдельная явно запрошенная задача.
- Новые словоформы известных слов проверяются редакторски. Введение новой лексики или грамматики по умолчанию не требуется.
- Имена файлов короткие и смысловые, по-английски: `dialogue-about-coffee.mp3`, `monologue-about-family.mp3`. Для текста и WAV используется тот же `file_stem`.
- Темп обычный разговорный: чёткая дикция, короткие естественные паузы, без намеренного замедления и фильтров изменения темпа. Для Ryan не использовать расслабленную или растянутую манеру. Замедление допустимо только по отдельной явной просьбе.

**Codex пишет и проверяет греческий текст.** Скрипт `scripts/greek-listening-practice.py` собирает актуальный контекст, проверяет словоформы, ссылки на источники, формат и сходство с уроками/предыдущими материалами. Затем запускает локальную озвучку и проверку через Whisper. Это не автономный генератор текста и не автоматическое доказательство правильной грамматики.

```sh
python3 scripts/greek-listening-practice.py context \
  --output data/listening-generated/practice/my-batch/context

python3 scripts/greek-listening-practice.py validate \
  data/listening-generated/practice/my-batch/my-dialogue/draft.json

/path/to/mlx-audio-venv/bin/python \
  scripts/greek-listening-practice.py render \
  data/listening-generated/practice/my-batch/my-dialogue/draft.json
```

Вся партия и снимок исходных учебных данных остаются в приватной `data/listening-generated/practice/`. В каждом комплекте сохраняются новый текст, роли, словарь, объяснение отличий от референсов, MP3/WAV и результаты проверок. Схема черновика и подробности — в ссылке из скилла; готовые примеры находятся в `2026-11-05-first-variants/`.

Исторические переозвучки уроков остаются в `data/listening-generated/role-dialogues/`. Они не считаются новыми упражнениями.
