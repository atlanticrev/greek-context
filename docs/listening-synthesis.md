# Локальная озвучка учебных диалогов

Постоянное предпочтение пользователя: **для греческого всегда использовать локальную LFM3-Audio**. Для диалогов нужны два разных голоса с постоянной привязкой к ролям и одна аккуратно собранная запись. Предпочтение также закреплено в `AGENTS.md`; исторические сравнения ниже не меняют этот стандарт.

**Текущий темп — обычный разговорный, без искусственного замедления.** Чёткая дикция не означает медленную речь. Для Ryan не задаётся расслабленная или растянутая манера. Старые замедленные профили ниже описаны только как история первых опытов.

Для **новых упражнений** действует [процесс генерации](listening-practice.md): монолог с одним голосом либо диалог ровно двух персонажей с двумя разными голосами. Исторические многоперсонажные переозвучки ниже не служат шаблоном для новых диалогов.

Производные записи хранятся в приватной папке `data/listening-generated/` отдельно от исходных аудиореференсов. Первый пример — `2026-11-05-petros-emine/`, диалог Петра и Эмине из референса `holst-c8ea17b1-dba7-4304-aaa3-2813fe7395ff`.

## Диалоги по ролям — текущий стандарт

Папка `data/listening-generated/role-dialogues/` содержит каталог и отдельные диалоги. В каждой папке:

- `script.json`: явная привязка ролей к `male-greek` / `female-greek`, текст реплик, связь с источником и примечания о распределении ролей.
- `dialogue.md` и `dialogue.txt`: текст с ролями и только произносимые слова.
- `parts/`: отдельные исходные реплики с голосом, SHA-256 и ключом повторного использования.
- `dialogue.mp3` и `dialogue.wav`: одна собранная запись; `native-assembled.wav` — до финальной нормализации громкости.
- `manifest.json`: параметры, голоса, монтажные интервалы и результаты проверки.
- `qa/`: обратное распознавание локальным Whisper, TXT/JSON и лог.

Роли устанавливаются по подписям в учебных изображениях, где они доступны. Границы предложений не считаются границами ролей. Группы соседних строк одного персонажа объединяются до синтеза. Служебные названия уроков и упражнений не озвучиваются. Скрипт проверяет точное сохранение текста после удаления только этих заголовков и нормализации пробелов.

Для сцен с тремя и более персонажами исходные роли и слова сохраняются, но несколько персонажей могут использовать один пресет: у установленной LFM доступны два греческих пресета. Это два чтеца; тембр чтеца не обязан совпадать с полом персонажа. Такие случаи явно отмечены в сценариях. В сборнике четырёх приветствий часть ролей восстановлена по смыслу, а не подтверждена печатными подписями.

Текущий профиль `natural-conversation-two-voices-v2`: по одной генерации на реплику, внешняя тишина обрезается с отступом 100 мс, края сглаживаются на 5 мс, громкость реплик предварительно выравнивается с ограничением усиления. Пауза между репликами — 350 мс, между мини-сценами — 1.4 с. Темп остаётся исходным, 1.0: фильтр изменения темпа не применяется. После сборки применяется общая нормализация loudnorm. Один и тот же `role` всегда использует один и тот же голос.

Запуск для одного сценария:

```sh
/path/to/mlx-audio-venv/bin/python \
  scripts/synthesize-role-dialogues.py \
  data/listening-generated/role-dialogues/petros-emine/script.json \
  --check-asr
```

Можно передать несколько путей `script.json`. Для всей партии — `data/listening-generated/role-dialogues/*/script.json`. Этот скрипт использует только LFM и проверяет наличие обоих греческих голосов в установленной модели.

## Модели и голоса

- **LFM3-Audio, Q8_0**: локальный Ollama, голос `female-greek`.
- **Qwen3-TTS-1.7B-CustomVoice, MLX 8bit**: голос `Serena`. Греческого нет в списке поддерживаемых языков установленной модели. Греческий текст передаётся с `language=auto`; результат экспериментальный и требует проверки до использования в обучении.
- **macOS Speech, Melina**: дополнительный локальный греческий голос для сравнения, если Serena искажает текст. Это системный синтезатор, а не ещё одна LLM.

Скрипт использует уже установленные модели и работающий Ollama. Он не скачивает модели, не перезапускает сервисы, не воспроизводит запись автоматически и не отправляет текст во внешние сервисы.

## Исторический профиль careful-reading-v1

Этот профиль использовался только в ранних записях. По текущему пожеланию пользователя он заменён обычной разговорной речью без замедления; повторный запуск скриптов использует новые настройки. Старые параметры сохранены здесь для понимания исходных опытов:

- Каждая реплика синтезируется отдельно; обе роли читает один женский голос.
- Убирается только внешняя тишина с сохранением отступов по 100 мс.
- Между репликами добавляется 600 мс тишины до изменения темпа.
- Темп готовой записи: `atempo=0.9`, без изменения высоты голоса. Добавленная пауза после этого составляет примерно 667 мс.
- Громкость приводится к `loudnorm=I=-18:TP=-1.5:LRA=11`.
- Для Qwen задаётся инструкция `Speak slowly and clearly, using careful pronunciation.`; temperature 0.8, top_k 50, top_p 1.0, repetition_penalty 1.05, max_tokens 512, seed 42 + номер реплики.
- Для Melina задаётся системная скорость 155 слов в минуту до дополнительного изменения темпа.

Итог: WAV PCM16 mono 24 kHz и MP3. Сохраняются текст, отдельные реплики, исходная сборка до обработки, параметры, SHA-256 и длительности. Заголовок упражнения из исходной транскрипции опускается, слова диалога сохраняются.

## Повторный запуск

Из корня проекта, с установленным окружением MLX Audio:

```sh
/path/to/mlx-audio-venv/bin/python \
  scripts/synthesize-listening-comparison.py \
  --source data/listening-reference-library/transcripts/holst-example.txt \
  --output data/listening-generated/2026-11-05-petros-emine
```

По умолчанию используется только LFM3. Параметры сравнения с другими движками сохранены для воспроизводимости прошлых опытов; применять их для новых греческих материалов можно только по явной просьбе пользователя. Можно указать `--ollama-url`. Совпавшие реплики используются повторно; итоговые сборки создаются заново.

## Проверка

Для первой партии выполнено обратное распознавание локальным whisper.cpp 1.8.4, полная multilingual large-v3: язык `el`, 8 потоков, beam 5, best-of 5, max-context 0, suppress-nst. Вход предварительно приведён к mono PCM16 16 kHz. TXT, JSON и логи находятся в подпапке `qa/`, результаты сравнения — в `quality.json` и README конкретной партии.

Слова сравниваются после удаления регистра, пунктуации и диакритики. Такой результат показывает расхождения распознавания, а не объективную оценку произношения, ударения или естественности. Полная проверка человеком по слуху не заявляется. Непригодные экспериментальные записи не добавляются к оригинальным аудиореференсам.

В первой попытке Qwen с temperature 0.3 и более длинной инструкцией возникли повторы и достижение лимита генерации. Частичные результаты сохранены в `attempts/01-qwen-low-temperature/`; они не входят в итоговую запись.

Описание интерфейса и параметров: [MLX Audio TTS](https://blaizzy.github.io/mlx-audio/api-reference/tts/), [реализация Qwen3-TTS](https://github.com/Blaizzy/mlx-audio/blob/main/mlx_audio/tts/models/qwen3_tts/qwen3_tts.py).
