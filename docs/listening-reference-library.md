# Библиотека аудиореференсов

Учебные аудио из Holst транскрибируются локально через whisper.cpp. Тексты, исходные результаты и связи с доской сохраняются в общей приватной папке data/listening-reference-library/.

## Назначение

- Дополнительный контекст о содержании учебных материалов.
- Референсы для новых похожих текстов и последующей озвучки.
- Проверяемая связь текста с оригинальной записью.
- Накопление следующих транскрипций в одной библиотеке.

Присутствие текста в библиотеке означает знакомство с учебным материалом. Оно не подтверждает владение языком.

## Содержимое

| Путь относительно библиотеки | Назначение |
| --- | --- |
| index.md | Каталог записей с названиями, длительностью и статусами |
| transcripts/*.md | Отдельные тексты с источником и замечаниями |
| transcripts/*.txt | Текст без служебной обвязки |
| context.md | Собранный дополнительный контекст |
| corpus.jsonl | Машиночитаемые записи для дальнейшей генерации |
| generation-references.jsonl | Итоговые записи без открытых замечаний, с фильтром reference_ready |
| manifest.json | Метаданные, связи с Holst и результаты проверок |
| inventory.json | Накопительный список исходников с SHA-256 |
| raw/primary/ | Исходное распознавание основной моделью: TXT, SRT, JSON, логи и параметры |
| raw/control/ | Контрольное распознавание второй моделью |
| raw/control-vad/ | Контрольное распознавание второй моделью с VAD |
| raw/experiments/ | Сохранённые пробные проходы |
| reviews/ | Явные редакторские правки и замечания отдельно от исходного ASR |
| work/ | Временные WAV для обработки |

Оригинальные MP3 остаются в assets/files/ соответствующей доски. Библиотека хранит ссылки и контрольные суммы, а не дублирует аудио.

## Выбор модели и параметры

Основная модель: полная многоязычная large-v3 в ggml без квантования. Контрольная: large-v3-turbo. Это практический выбор в пользу качества исходного распознавания с дополнительным сравнением; он не означает гарантии безошибочного греческого текста.

Параметры: язык el, transcription без перевода, beam size 5, best-of 5, начальная температура 0 с обычным fallback, отключён перенос текстового контекста между окнами. Голосовые участки выделяются Silero VAD v6.2.0 с порогом 0.35, минимальной речью 100 мс и отступом 200 мс.

Модели находятся в пользовательском кэше Library/Caches/greek-context/whisper.cpp/. Полные команды, SHA-256 моделей и исходников записываются для каждого прохода. Для первой партии использовался whisper-cpp 1.8.4 с Metal на Apple Silicon.

Источники:

- [Официальная документация whisper.cpp](https://github.com/ggml-org/whisper.cpp).
- [Модели ggml и контрольные суммы](https://github.com/ggml-org/whisper.cpp/blob/master/models/README.md).
- [Карточка large-v3](https://huggingface.co/openai/whisper-large-v3).
- [Карточка large-v3-turbo](https://huggingface.co/openai/whisper-large-v3-turbo).

## Повторный запуск и следующие материалы

Из корня проекта:

    python3 scripts/transcribe-listening.py \
      --model $HOME/Library/Caches/greek-context/whisper.cpp/ggml-large-v3.bin \
      --model-name large-v3

Контрольный проход:

    python3 scripts/transcribe-listening.py \
      --model $HOME/Library/Caches/greek-context/whisper.cpp/ggml-large-v3-turbo.bin \
      --model-name large-v3-turbo \
      --pass-name control-vad

Дополнительный диагностический проход без VAD можно сохранить с --pass-name control --no-vad. Он не заменяет сверку итогового текста.

Завершённые проходы повторно не запускаются, если совпадают исходник, модель и параметры. Новые файлы добавляются после следующего импорта Holst. Одинаковое аудио определяется по SHA-256; все его размещения на доске сохраняются в метаданных.

Другую импортированную доску можно указать через --board-id. Существующие источники других досок остаются в общей библиотеке.

После редакторских правок пересобрать библиотеку:

    python3 scripts/transcribe-listening.py --publish-only

## Проверка и редактура

Исходные результаты ASR сохраняются. Исправления задаются в reviews/<ID>.json с полями status, title, text, notes и audio_sha256. Для привязки к конкретному проходу указывается primary_json_sha256.

Статусы: automatic_transcript — автоматический результат; text_reviewed — текстовая сверка проходов; source_checked — для уточнения текста использован учебный источник; needs_audio_check — осталось конкретное сомнение. Они не обозначают полную проверку по слуху. Совпадение моделей и вероятность токенов не заменяют прослушивание. Непроверенные или неразборчивые фрагменты отмечаются явно.

whisper.cpp иногда выводит отдельные байтовые фрагменты токенов как невалидный UTF-8 внутри полного JSON. Скрипт сохраняет оригинальные байты в .json.original-bytes и нормализует только этот технический вывод. Замены внутри полного текста сегмента запрещены: такой случай завершает обработку ошибкой.

## Использование для генерации

1. Выбрать подходящий референс и прочитать его замечания.
2. Выделить тему, коммуникативную задачу, длину и используемые конструкции.
3. Для фонетических упражнений отдельно учитывать пометки о словах, слогах и неоднозначном написании.
4. Создать новый текст с изменёнными словами и обстоятельствами, учитывая реальный уровень ученика.
5. Сохранять производные материалы отдельно с указанием ID референса и статуса generated.
6. До озвучки проверить греческий текст.

Не заменять исходную транскрипцию сгенерированным вариантом. Приватная библиотека не загружается во внешние сервисы автоматически.
