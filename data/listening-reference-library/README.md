# Аудиореференсы для греческого

Общая локальная библиотека исходных учебных аудио и расшифровок. Следующие транскрипции добавляются сюда же; исходники и редакторские правки сохраняются отдельно.

Полная large-v3 используется как основная модель. Сохранены контрольные проходы large-v3-turbo с VAD и без него. Спорные пропуски проверялись повторным распознаванием фрагментов; написание уточнялось по локальным изображениям учебных заданий.

Тексты являются учебными референсами. Они не подтверждают, что ученик владеет материалом. Статусы source_checked и text_reviewed описывают способ сверки, а не обещают полную проверку по слуху.

Для генерации использовать итоговое поле text и учитывать content_type, reference_ready и notes. Сырые проходы ASR нужны для проверки происхождения, а не как готовый текст. Фонетические списки использовать для фонетики; для новых диалогов выбирать диалоги и связные рассказы.

Новые тексты и озвучки, созданные на основе библиотеки, сохранять отдельно от оригинальных транскрипций с указанием reference_id и статуса generated.
