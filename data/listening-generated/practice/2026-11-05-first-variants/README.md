# Первые новые упражнения на пройденном греческом

Оба текста написаны заново. Исходные диалоги служили референсами по конструкциям и темам; это не их переозвучка. Героини и ситуации вымышлены.

Диалог читают два постоянных голоса LFM, `male-greek` и `female-greek`; монолог — один `female-greek`. Использован профиль аккуратного чтения с паузами и замедлением на 10% без изменения высоты голоса.

Темы и грамматика взяты из текущего профиля, лексика — из словаря и проверенных учебных референсов. Не встретившиеся в корпусе словоформы известных слов проверены редакторски и описаны в `inflection_reviews`; неразобранных слов нет. Это не утверждение, что ученик владеет всеми использованными словами.

В каждом комплекте есть README с целевым словарём, источниками и отличиями, `draft.json`, `validation.json`, исходные реплики и параметры синтеза. [Снимок учебного контекста](context/context.md) сохранён для воспроизводимости.

Whisper large-v3 распознал слова обоих текстов без расхождений после нормализации регистра, пунктуации и диакритики. Проверены голоса ролей и контрольные суммы. Отдельно проверено, что валидатор отклоняет неверное число голосов/персонажей, копию урока, дубликат предыдущего упражнения и неразобранное новое слово. [Протокол](verification.json).

Редакторская проверка текста выполнена Codex. Полная проверка произношения человеком по слуху не заявляется.
