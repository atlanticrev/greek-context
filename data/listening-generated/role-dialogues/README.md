# Диалоги по ролям — LFM

Историческая партия: 9 диалоговых записей библиотеки, 7 отдельных сцен и 2 сборника. В репозитории доступен один итоговый MP3 на исходную запись; WAV можно восстановить локально. В сборниках мини-сцены разделены увеличенной паузой.

Для каждой роли явно закреплён `male-greek` или `female-greek`. Реплики синтезированы отдельно, громкость выровнена, порядок сохранён. Эти исторические записи были созданы с замедлением на 10% без изменения высоты голоса; новые записи по текущему скиллу используют нормальный темп без замедления.

## Сцены с несколькими персонажами

Исходные персонажи и слова сохранены. Если персонажей больше двух, несколько ролей читает один голос. Это два чтеца, а не уникальная имитация каждого персонажа. В сцене вечеринки обе героини — женщины; для различения Пάολα читает мужской чтец, Ελένη — женский. Аналогичные особенности распределения описаны в `dialogue.md` и `script.json` каждой сцены.

Роли сверены по подписям в учебных изображениях, где они доступны. В сборнике четырёх приветствий печатного источника нет, а часть реплик последней сцены распределена по смыслу; это явно помечено как редакторское предположение.

## Проверка

Проверено точное сохранение произносимого исходного текста после удаления только заголовков и нормализации пробелов, постоянство голоса каждой роли, наличие всех реплик, SHA-256 частей и итоговых файлов, отсутствие цифрового клиппинга. Весь звук повторно распознан локальным whisper.cpp large-v3.

Расхождения ASR в таблице не равны числу ошибок произношения: например, χαίρω/χαίρο и ψηλή/ψιλή звучат одинаково, но пишутся по-разному; встречаются варианты иностранных имён. Слова сравнивались без регистра, пунктуации и диакритики. Полная проверка человеком по слуху не проводилась. Для точечной сверки сохранены `qa/whisper.txt` и `qa/differences.json`; исходное аудио Holst остаётся в библиотеке референсов.
